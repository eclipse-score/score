.. _modules:

Modules
=======

A **Module** is an independently developed and released architectural building
block consisting of one or more components that contribute to the realization
of one or more :ref:`features <features>` of the platform.

A module is developed, built, verified, versioned, and released from its
corresponding module repository.

For further explanation of the relationship between features, modules, and
components, see the `Building Blocks Concept
<https://eclipse-score.github.io/process_description/main/general_concepts/score_building_blocks_concept.html>`_.


Module Ownership
----------------

The entries on this page provide an overview of the software modules
developed as part of S-CORE and links to their current development
documentation.

The authoritative specification of a module, including its requirements,
architecture, design, implementation, and verification evidence, is
maintained in the respective module repository.

Module Traceability
-------------------

Module repositories depend on the S-CORE platform repository to establish
traceability to platform requirements and architecture.

The S-CORE platform repository does not depend on module repositories.
References from the platform documentation to module documentation are
therefore provided as links to the published documentation.
